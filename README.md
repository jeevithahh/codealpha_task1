# Credit Scoring Model

## Objective
Predict an individual's creditworthiness using past financial data.

## Dataset
German Credit Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn

## Algorithms Used
1. Logistic Regression
2. Decision Tree
3. Random Forest

## Results

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 74.5% |
| Decision Tree | 72.5% |
| Random Forest | 77.0% |

## Best Model
Random Forest achieved the highest accuracy of 77%.

## How to Run

```bash
pip install pandas numpy scikit-learn
python main.py
